# CIND820 Homelessness Mortality Analysis

This repository contains the supporting materials, datasets, exploratory analysis, and reports for the CIND820 Big Data Analytics Project.

## Research Questions

1. What trends and patterns exist in deaths among shelter residents and people experiencing homelessness in Toronto over time?

2. How do mortality patterns correspond with shelter occupancy, capacity utilization, active homelessness, housing placements, and shelter returns?

3. What shelter-system and population characteristics appear most strongly associated with elevated mortality periods?

## Datasets

- Deaths of Shelter Residents
- Homeless Deaths by Month
- Shelter System Flow
- Daily Shelter Occupancy
- Daily Shelter Occupancy & Capacity
